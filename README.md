# M-Vision OS — site estático

Abra `index.html` para testar. Para publicar na internet, envie o conteúdo deste pacote a um host estático HTTPS, por exemplo GitHub Pages.

O site inclui relógio/data, atalhos, temas, ferramentas compatíveis com navegador e informações limitadas do dispositivo. ISNET TV abre sua página oficial do Google Play; não é incorporado como app Android.
